# Checkpoints

Copied from the original training runs:

- `emulator_stage1_base_best.pth`: best deterministic stage-1 model
- `emulator_stage2_best.pth`: best stage-2 model from the initial stage-2 run
- `emulator_stage2_best_resumed.pth`: continued stage-2 checkpoint from the resumed run

These are included because they are small enough for a normal repository and are directly tied to the main two-stage training pipeline.
